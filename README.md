# مرسل الرسائل الجماعي للعملاء (SmsBulkSender)

تطبيق أندرويد بسيط لإرسال رسائل SMS جماعية لجهات اتصال محفوظة على الهاتف،
باستخدام رصيد شريحة الاتصال مباشرة (بدون إنترنت أو سيرفر)، مع تأخير زمني
قابل للتعديل بين كل رسالة لتقليل احتمال حظر الشريحة من قبل الشبكة.

## بناء ملف APK أونلاين بدون تثبيت أي برنامج (الطريقة الموصى بها)

المشروع يحتوي الآن على كل ملفات Gradle Wrapper + إعداد GitHub Actions جاهز،
بحيث يمكنك الحصول على ملف APK جاهز للتثبيت مباشرة من الإنترنت بدون تثبيت
Android Studio على جهازك:

1. أنشئ حساب مجاني على [github.com](https://github.com) إذا لم يكن لديك.
2. أنشئ مستودع (Repository) جديد **خاص Private** (حتى لا يظهر كود التطبيق للعموم).
3. ارفع محتويات مجلد `SmsBulkSender` كاملة إلى المستودع (يمكنك السحب والإفلات
   لملف الـ zip بعد فك ضغطه عبر واجهة GitHub في المتصفح مباشرة: زر **Add file
   → Upload files**).
4. بعد الرفع، افتح تبويب **Actions** أعلى صفحة المستودع — سيبدأ بناء الـ APK
   تلقائياً (سيأخذ حوالي 3-5 دقائق).
5. بعد انتهاء البناء بنجاح (علامة ✔ خضراء)، افتح الـ workflow المكتمل، وفي
   الأسفل ستجد قسم **Artifacts** فيه ملف باسم `app-debug-apk` — حمّله، فك
   ضغطه، وبداخله ملف `app-debug.apk` هو التطبيق الجاهز للتثبيت على هاتفك.
6. لتثبيت الملف على الهاتف: فعّل خيار "تثبيت من مصادر غير معروفة" (Install
   unknown apps) لمتصفحك أو تطبيق الملفات، ثم افتح الـ APK وثبّته.

هذه الطريقة مجانية بالكامل (GitHub Actions تعطي وقت تشغيل مجاني شهرياً كافٍ
لهذا الحجم من المشاريع) ولا تحتاج منك أي تثبيت على جهاز الكمبيوتر.

> ⚠️ **تنبيه بخصوص "مواقع بناء APK أونلاين" العامة** (ارفع مشروعك واحصل على
> APK): هذه المواقع غالباً مخصصة لمشاريع محددة (مثل Flutter أو React Native)
> ولا تدعم مشروع Kotlin/Gradle عادي مثل هذا، وبعضها غير موثوق من ناحية أمان
> الكود الذي ترفعه. GitHub Actions هي الطريقة الرسمية والموثوقة والمجانية
> لهذا النوع من المشاريع.

## أو: البناء المحلي عبر Android Studio (البديل التقليدي)


1. افتح Android Studio (أحدث نسخة مستحسن).
2. اختر **Open** وحدد مجلد المشروع `SmsBulkSender`.
3. اترك Android Studio يقوم بمزامنة Gradle تلقائياً (سيولّد ملفات
   Gradle Wrapper بنفسه إذا لم تكن موجودة).
4. وصّل هاتف أندرويد فعلي عبر USB (فعّل خيارات المطور + USB Debugging)
   — **ملاحظة**: إرسال SMS لا يعمل على المحاكي (Emulator) لأنه لا يملك
   شريحة اتصال حقيقية.
5. اضغط Run ▶ لتثبيت التطبيق على الجهاز.

## كيفية الاستخدام

1. عند أول تشغيل سيطلب التطبيق صلاحيتي **جهات الاتصال** و **إرسال الرسائل** — يجب الموافقة عليهما.
2. اختر جهات الاتصال (يمكنك البحث، أو الضغط على "تحديد الكل").
3. اضغط "التالي".
4. اكتب نص الرسالة (يمكنك استخدام `{name}` داخل النص ليتم استبدالها تلقائياً باسم كل عميل).
5. حدد مدة التأخير بالثواني بين كل رسالة (10 ثانية افتراضياً، لا يُنصح بأقل من 5-10 ثانية).
6. اضغط "بدء الإرسال". يمكنك إغلاق الشاشة والتطبيق سيستمر بالإرسال في الخلفية
   (سيظهر إشعار دائم يوضح التقدم، مع زر لإيقاف الإرسال في أي وقت).

## ملاحظات مهمة

- التطبيق **للاستخدام الشخصي/الداخلي فقط** ولا يصلح للنشر على Google Play
  بصيغته الحالية، لأن Google تقيّد صلاحيات SEND_SMS/READ_SMS بشدة إلا
  لتطبيقات الرسائل الافتراضية الكاملة.
- حتى مع التأخير، الشبكات المحلية (زين / أورنج / أمنية) قد تضع حدود يومية
  غير معلنة على عدد الرسائل من رقم عادي (غير تجاري) — يُفضل تجربة كميات
  صغيرة أولاً (10-15 رسالة) قبل الإرسال لكامل القائمة.
- في حال وجود شريحتين (Dual SIM)، الكود الحالي يستخدم الشريحة الافتراضية
  للرسائل المحددة في إعدادات الهاتف. يمكن إضافة دعم اختيار الشريحة لاحقاً
  عبر `SubscriptionManager` إذا احتجت ذلك.
